# kickoff

입력: 사용자가 준 `시작 HH:MM, 과제 마감 HH:MM`. 없으면 먼저 묻는다.

1. 환경 점검: `bash /tmp/kit/scripts/preflight.sh`를 한 번 실행하고, 결과 중 과제에 영향 있는 것만 docs/TASK.md '환경' 칸에 3~5줄로 적는다(Python 버전, 쓸 수 있는 웹 패키지, 포트, git 사용자 설정).
2. README 읽기: 과제 루트의 README.md와 README가 가리키는 파일만 읽는다. 데이터 파일은 앞부분만.
3. docs/TASK.md 채우기:
   - 사실: README에 적힌 것만. 출처 문장 위치를 괄호로.
   - 가정: 내가 추정한 것. 담당자에게 확인 전까지 가정.
   - 열린 질문: 결과를 바꾸는 것만. 경계값, 예외 우선순위, 단위·시간대, 결측, 용어, 역할·권한.
   - 안 할 일: 이번에 만들지 않을 것.
   - 완료 조건: 확인 가능한 문장으로. 각 조건에 R1, R2… 번호.
   - 필수 산출물 경로: README·안내가 요구하는 파일 이름과 위치(예: 소스, AI_COLLABORATION.md, HOW_TO_USE.md). 안내와 다르면 뼈대 파일을 그 위치로 옮긴다.
4. 시간표: 시작·마감 시각으로 docs/RUNBOOK 비율(계약 20분 / 인터뷰 20분 / 계획 10분 / 최소 E2E 30분 / 반복 / 기능 동결 = 과제 시간의 80%)을 계산해 TASK.md 맨 위에 시각으로 적는다.
5. AI_COLLABORATION.md '작업 방식'에 첫 줄을 적는다(사용 모델, 키트 커밋 해시는 사용자가 알려 주면).
6. 결과를 10줄 안으로 보고하고 멈춘다. 다음 단계는 $interview.

하지 않을 것: 구현, 패키지 설치, README 밖 추측을 사실 칸에 쓰기.
