# collab-log

사건이 생긴 그 자리에서 쓴다. 나중에 기억으로 쓰지 않는다.

AI_COLLABORATION.md '사건 로그'에 아래 형식으로 한 건 추가:

```
### E<번호>. <한 줄 제목> (HH:MM)
- 증상: 무엇이 어떻게 틀렸나 (화면·출력 그대로)
- 재현: 실행한 명령 또는 화면 조작 순서
- 원인: 확인된 원인. 추정이면 '추정'이라고 쓴다
- AI 제안: 무엇을 제안했나
- 판단: 채택 / 수정 / 폐기 — 이유
- 확인: 고친 뒤 실행한 명령과 결과
- 커밋: <해시 앞 7자리>
```

규칙:
- 실제로 일어난 것만. 명령과 결과는 터미널·git log에서 확인 가능한 것만 적는다.
- '수정'·'폐기'한 제안이 중요하다. 왜 그대로 받지 않았는지 근거를 쓴다.
- 사용자가 직접 발견한 것(Browser 확인 등)은 '발견: 사용자'로 표시한다.
- 3~8건이면 충분하다. 사소한 오타 수정은 쓰지 않는다.
