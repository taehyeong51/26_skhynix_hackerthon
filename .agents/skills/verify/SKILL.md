# verify

1. scripts/verify.sh의 '검사 목록'을 TASK.md 완료 조건(R번호)에 맞게 채운다. 조건 하나에 `check` 한 줄 이상. 확인할 수 없는 조건은 `skip "R3 ..." "이유"`로 남긴다.
   - 테스트 실행은 `tests_ran`으로 감싼다(0건 실행이면 실패).
   - 서버가 있으면 `http_status`와 `bound_all`(0.0.0.0 바인딩)을 넣는다.
2. `bash scripts/verify.sh`를 실행하고 결과를 그대로 보여 준다. exit 2(검사 0건)는 실패다.
3. 표로 정리: `R번호 | 확인 방법 | 결과(통과/실패/미실행) | 근거(출력 한 줄)`. 미실행을 통과로 쓰지 않는다.
4. 사람이 직접 할 Browser 확인 목록을 만든다. 결과는 사용자에게 받아 적는다.
   - 로그인 / 로그아웃 / 잘못된 비밀번호
   - 역할별로 보이면 안 되는 화면·버튼, 주소를 직접 쳐서 접근
   - 새로고침 후 상태 유지
   - 빈 값·잘못된 형식·경계값 입력
   - 핵심 동작 버튼 연타, 처리 중 재요청
5. 실패가 있으면 고칠 순서를 제안하고 멈춘다. 동결 뒤라면 고치지 말고 HOW_TO_USE '알려진 한계'에 적을지 묻는다.
6. 마지막 결과 요약(통과 n / 실패 n / 미실행 n)을 HOW_TO_USE.md '검증 경로'에 반영한다.
