## 프롬프트를 쓰는 방식

규칙은 AGENTS 블록과 스킬이 이미 갖고 있습니다. 프롬프트에는 그 순간에만 아는 정보와 이번 턴의 경계만 넣습니다.

1. **한 턴에 한 일.** 끝나는 지점을 정해서 멈추게 합니다.
2. **읽을 곳을 지정합니다.** 파일 전체를 읽히지 않습니다(비용).
3. **하지 말 것은 이번 턴에 해당하는 것만.** 규칙 전체를 다시 쓰지 않습니다.
4. **보고 형식을 정합니다.** 제가 빠르게 판단할 수 있는 모양으로 받습니다.
5. **상황 정보만 채웁니다.** 시각, R번호, 포트, 담당자 답변 원문.

`<...>`는 바꿔 넣을 자리입니다. 파일마다 `## 언제`, `## 프롬프트`, `## 정상이면`, `## 아니면` 순서입니다. 정상 기준은 AI 결과를 읽을 때 제가 확인할 항목이고, `아니면`은 그대로 이어서 붙일 후속 프롬프트입니다.

## 스킬이 인식되지 않을 때

프롬프트 앞에 경로를 붙입니다.

```
.agents/skills/<스킬 이름>/SKILL.md 를 읽고 그대로 따라서 아래를 진행해.
```

외부 스킬(`systematic-debugging`, `ponytail` 등)은 `--extras core,web`로 설치했을 때만 있습니다. 없으면 `$이름` 줄을 빼고 프롬프트의 나머지만 쓰면 됩니다.
