# PROMPTS — 단계별 입력 프롬프트

복사해서 쓰는 프롬프트 모음입니다. `< >` 안만 바꿉니다. 시험 중에는 터미널에서 `cat /tmp/kit/docs/PROMPTS.md`로 열어 복사합니다. 과제 폴더로 복사하지 마세요(제출물에 섞임).

- 한글이 터미널에서 깨지면 에디터에 쓰고 복사해 붙입니다. Codex 입력창 줄바꿈은 Ctrl+J입니다.
- 프롬프트는 짧게 유지합니다. 길게 설명할 내용은 이미 스킬과 AGENTS 블록에 있습니다.
- 시각표는 [RUNBOOK](RUNBOOK.md), 커밋 규칙은 [GIT_RULES](GIT_RULES.md)를 따릅니다.

## S1. 계약서 (0~20분)

```
$kickoff 시작 <19:05>, 과제 마감 <22:05>. 키트 커밋은 <7자리>. 코드는 쓰지 마.
```

TASK.md를 받은 뒤 확인합니다.
```
TASK.md에서 README에 근거가 없는데 '사실'에 들어간 항목이 있으면 '가정'으로 옮겨. 완료 조건 R번호마다 확인 방법이 비어 있으면 표시만 해.
```

## S2. 담당자 인터뷰 (20~40분)

```
$interview 첫 질문 하나만 복사용으로 만들어.
```

담당자 답을 받을 때마다:
```
담당자 답: "<붙여넣기>"

```

마무리:
```
남은 질문은 가정으로 돌리고 합의문 복사용 문구를 만들어.
```
```
담당자가 합의문을 확인했어: "<답>". TASK.md 합의 칸에 시각과 함께 기록하고 커밋해 (docs: 계약서와 합의).
```

## S3. 계획 (40~50분)

```
$plan 기능 동결은 <21:24>. 슬라이스는 최소 E2E부터, 예상 시간 합계가 동결을 넘으면 뒤에서부터 '안 할 일' 후보로 표시해.
```

계획을 받은 뒤:
```
<슬라이스 이름>은 빼서 '안 할 일'로 옮기고 DECISIONS에 이유를 한 줄 남겨. 나머지 계획대로 진행.
```

## S4. 최소 E2E (50~80분)

```
$slice 첫 슬라이스(최소 E2E). 서버는 0.0.0.0:<포트>. 끝나면 실행 명령과 결과를 보여주고 멈춰.
```

Browser 확인 직후 (사람이 직접 보고 나서):
```
Browser 확인 결과: 로그인 <OK/문제>, 새로고침 <…>, 잘못된 입력 <…>, 연타 <…>. 문제는 $collab-log로 기록하고 고칠 순서를 제안해.
```

자동화 (Playwright가 있을 때):
```
$e2e 로그인·권한·새로고침·잘못된 입력·연타 시나리오를 scripts/e2e.py에 채우고 실행해. 선택자는 실제 화면에서 확인해.
```

이정표:
```
최소 E2E와 화면 확인이 끝났으니 커밋 상태를 보여주고 m1-e2e 태그를 붙여.
```

```

## S6. 막혔을 때

같은 실패가 반복될 때:
```
$systematic-debugging 증상: <출력 그대로>. 재현 명령부터 만들고, 원인 확인 전에는 고치지 마.
```

AI 제안을 고치거나 버렸을 때:
```
$collab-log 방금 건: 증상 <…>, AI 제안 <…>, 판단 <수정/폐기> 이유 <…>. 확인 명령과 커밋 해시까지 기록해.
```

범위를 줄여야 할 때:
```
남은 시간 <N>분. 완료 조건 중 못 할 것을 '안 할 일'로 옮길 후보와 그 영향을 3줄로 보여줘. 결정은 내가 해.
```

Codex가 설치를 시도할 때 (Esc로 끊은 뒤):
```
패키지 설치와 외부 네트워크는 금지야. 이미 설치된 것(preflight 결과)과 표준 라이브러리로 대안을 제시해.
```

## 상황별

컨텍스트가 길어졌을 때:
```
docs/HANDOFF.md를 지금 상태로 갱신하고 커밋해. 다음 세션이 그 파일만 읽고 이어갈 수 있게.
```

새 세션에서 이어갈 때:
```
docs/HANDOFF.md → docs/TASK.md → git log --oneline -10 순서로 읽고, 다음 할 일 1개만 말해. 아직 실행하지 마.
```

접속이 끊겼다 돌아왔을 때:
```
git status와 git log -3를 보여주고, docs/HANDOFF.md 기준으로 끊기기 직전 작업이 커밋됐는지 확인해.
```

두 번째 탭에 일을 맡길 때 (서로 다른 파일만):
```
<파일 경로>만 수정해서 <기대 동작>을 만들어. 확인 명령: <명령>. 다른 파일은 건드리지 말고 커밋하지 마. 끝나면 diff와 실행 결과만 보여줘.
```

중요한 산출물 검토 (별도 세션):
```
<파일>을 처음 보는 리뷰어로 읽고, 요구사항(docs/TASK.md 완료 조건)과 어긋나는 점과 실패 경로 누락만 지적해. 수정은 하지 마.
```

```
키트를 껐어. DECISIONS에 '키트 제거: <이유>' 한 줄 남기고 순정 방식으로 계속해.
