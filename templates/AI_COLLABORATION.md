# AI_COLLABORATION

## 작업 방식
- 사용 도구·모델:
- 진행: 과제 계약서 작성 → 담당자 인터뷰와 합의 → 슬라이스 계획 → 슬라이스마다 테스트 먼저·실행 확인·커밋 → 검증 → 정리
- 검증 원칙: 실행 결과로만 완료 판단. 실행된 검사 0건은 실패로 처리.
- 사람이 직접 한 것: 담당자 질문 전송, 범위 결정, Browser 화면 확인, 최종 검토
