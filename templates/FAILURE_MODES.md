# FAILURE_MODES — 핵심 동작의 실패 경로

원칙: 실패하면 기존 적용 결과를 보존하고, 사용자에게 이유를 보여 준다.

## <핵심 동작 이름> (예: 생성 / 재생성 / 적용)
| 경로 | 입력·상황 | 시스템 동작 | 기존 결과 | 사용자에게 보이는 것 | 확인한 테스트 |
| --- | --- | --- | --- | --- | --- |
| 정상 |  |  |  |  |  |
| 중복·동시 요청 | 처리 중 재요청, 버튼 연타 |  |  |  |  |
| 제약 불충족 | 입력이 조건을 만족하지 못함 |  |  |  |  |
| 내부 실패 | 계산·검증·저장 오류 |  |  |  |  |
| 권한 없음 | 다른 역할이 직접 호출 |  |  |  |  |
